# FloppyTime

**Play the PC games you grew up with. Together. Online.**

FloppyTime is a free, open-source launcher for DOS, Windows 3.x and Windows 95/98 games. Point it at a game you own (a folder, a CD image, a GOG or Steam copy), press Play, and invite a friend. It works out how to run the game, fixes what it can, and connects players directly to each other. No accounts, no servers to rent and no ports to forward.

> **Status: in development.** Nothing is released yet. Windows is tested; Linux and macOS are in progress.

### Principles

- **Your games, your copies.** FloppyTime never downloads or shares commercial games, Windows or BIOS files.
- **No required server.** If this project disappeared tomorrow, FloppyTime would keep working.
- **Profiles are data, not code.** A profile can change settings; it can never run a program. Every profile is signed.

### Get involved

- A game doesn't work? [Open a game report](https://github.com/floppytime/floppytime/issues/new/choose), or use **Help > Report a problem** inside the app.
- Made a game work? Share its profile in [profiles](https://github.com/floppytime/profiles).
